# Reescrita

Site da Reescrita, editora de livros em papel reciclável. Projeto integrado.

Arquivos: `index.html` (site) e `books.json` (catálogo publicado). Livros cadastrados na área administrativa ficam no navegador; para publicá-los a todos, use "Exportar catálogo" e substitua o `books.json` neste repositório.
